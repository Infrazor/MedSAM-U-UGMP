# MedSAM-U: UGMP Implementation

Implementation of the Uncertainty-Guided Multi-Prompt (UGMP) stage from the research paper:

MedSAM-U: Uncertainty-Guided Auto Multi-Prompt Adaptation for Reliable MedSAM

This project was completed as part of the IEEE SMC Student Branch Chapter, Kalyani Government Engineering College Research Internship Programme 2026.

## About

MedSAM is a medical image segmentation model based on the Segment Anything Model (SAM). It uses prompts such as bounding boxes to identify the region that needs to be segmented.

The segmentation result can change when the initial bounding box is slightly inaccurate.

UGMP addresses this by generating multiple slightly different bounding-box prompts and observing how the segmentation changes for each prompt. The differences between the predictions are then used to estimate segmentation uncertainty.

This repository contains a practical implementation of the UGMP stage.

> Note: This project focuses on the UGMP portion of MedSAM-U. It is not a complete reproduction of the full MPA-MedSAM, UGMP, and UGPA framework or all experiments reported in the research paper.

## Implementation

### 1. Bounding Box Generation

An initial bounding box is used as the starting prompt.

Five slightly perturbed bounding boxes are generated by applying small changes to the original coordinates.

The purpose is to observe how small changes in the prompt affect the segmentation.

### 2. MedSAM Inference

Each generated bounding box is passed independently through MedSAM.

For every prompt, the model produces a segmentation prediction.

Box 1 → Mask 1
Box 2 → Mask 2
Box 3 → Mask 3
Box 4 → Mask 4
Box 5 → Mask 5

### 3. Probability Maps

The probability outputs from the different predictions are retained instead of using only the final binary masks.

These probability maps provide information about the model's prediction at each pixel.

### 4. Mean Probability

The probability maps from the five predictions are combined to obtain a mean probability map.

This gives an aggregated prediction from the different prompt variations.

### 5. Entropy-Based Uncertainty

Pixel-wise entropy is calculated from the probability information.

For a binary prediction:

H(p) = -p log(p) - (1-p) log(1-p)

Lower entropy indicates greater confidence, while higher entropy indicates greater uncertainty.

Regions where the predictions disagree are expected to have higher uncertainty.

### 6. Uncertainty Visualization

The entropy values are visualized as an uncertainty map.

The uncertainty map can also be overlaid on the original medical image.

In the implemented example, higher uncertainty was mainly observed around the target boundary.

## Running the Project

### 1. Clone the repository

git clone https://github.com/Infrazor/MedSAM-U-UGMP.git
cd MedSAM-U-UGMP

### 2. Install dependencies

pip install -r requirements.txt

### 3. Set up MedSAM

Clone or install the official MedSAM repository according to its setup instructions.

Download the required MedSAM checkpoint and update the checkpoint path in the notebook.

### 4. Open the notebook

Open:

UGMP.ipynb

The notebook can be run using Google Colab or a local Jupyter environment with a suitable GPU.

### 5. Run the notebook

Run the cells sequentially to:

1. Load the medical image
2. Load the MedSAM model
3. Set the initial bounding box
4. Generate multiple perturbed boxes
5. Generate segmentation masks
6. Generate probability maps
7. Calculate mean probability
8. Calculate entropy
9. Visualize the uncertainty map

## Research Paper Context

The original paper proposes MedSAM-U as an uncertainty-guided framework for reliable medical image segmentation. It combines MPA-MedSAM, UGMP, and UGPA. The paper describes generating multiple perturbed bounding boxes, obtaining multiple segmentation predictions, aggregating the predictions, and estimating uncertainty using entropy before using uncertainty to guide prompt adaptation.

This repository implements the UGMP uncertainty-estimation idea as a standalone prototype for study and experimentation.
